# PowerBI-project_Blinkit-Sales-Analysis
🛒 Blinkit Sales Analysis Dashboard | Power BI
📌 Project Overview
The Blinkit Sales Analysis Dashboard is an interactive Power BI project built to analyze Blinkit's grocery sales performance.
It provides business insights into sales, outlet performance, customer ratings, product categories, and inventory distribution through dynamic
visualizations and KPIs.
The dashboard enables stakeholders to monitor business performance, identify high-performing products and outlets, and make
data-driven decisions using interactive filters and charts. A well-structured README helps explain the project, its purpose,
and usage for GitHub visitors.
🎯 Objectives
Analyze total sales performance.
Compare outlet performance by location and size.
Identify top-selling item categories.
Evaluate customer ratings.
Monitor product distribution across outlet types.
Build an interactive business dashboard for decision-making.

🔍 Business Insights
Total sales reached $1.20 Million.
Regular fat products contribute more sales than Low Fat products.
Tier 3 outlets generate the highest revenue.
Medium-sized outlets contribute the maximum sales.
Fruits, Snacks, Household, and Frozen Foods are among the highest-selling categories.
Supermarket Type 1 records the highest total sales.
Average customer rating remains around 3.9, indicating satisfactory customer experience.
